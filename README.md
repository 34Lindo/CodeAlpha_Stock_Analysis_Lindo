Investment Portfolio & Stock Analysis

This repository contains the Investment Portfolio Project analyzing major stocks and cryptocurrencies. It includes historical price analysis, risk assessment, performance metrics, charts, and a final report.

1. Project Overview

The goal of this project is to:

Analyze the performance of Apple (AAPL), Tesla (TSLA), and JPMorgan Chase (JPM) over the past 12 months

Analyze a cryptocurrency portfolio including Bitcoin (BTC), Ethereum (ETH), and Solana (SOL)

Compare returns, risk, volatility, and trends

Build a hypothetical investment portfolio with rational allocation

2. Stock Analysis

The stock analysis covers:

Price trends: daily and monthly closing prices

Return analysis: monthly and cumulative returns

Risk assessment: volatility, beta, max drawdown

Insights: recommendations for long-term holding or speculative investment

Stocks Analyzed:

Company	Ticker	Sector
Apple	AAPL	Technology (Hardware & Services)
Tesla	TSLA	Electric Vehicles & Energy
JPMorgan Chase	JPM	Banking & Financial Services
3. Cryptocurrency Analysis

The crypto analysis includes:

Historical daily/monthly prices for BTC, ETH, SOL

Monthly returns and volatility

Portfolio recommendations based on risk profile

4. Portfolio Allocation

Total portfolio: ₹1,00,000

Allocation among stocks, ETFs, and cryptocurrencies with rationale

Diversification strategy to balance risk and return
